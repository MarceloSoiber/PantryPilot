# Contratos

Este diretório receberá os contratos versionados e independentes de framework do fluxo
de recomendação. Nenhum schema foi criado ainda: a primeira versão depende da
confirmação do contrato UI/API e das restrições alimentares do MVP.

Quando houver consumidores reais, os contratos devem cobrir pedido, resposta, erro,
citações e avisos de segurança. A aplicação e a infraestrutura não devem ser
dependências desses contratos.
