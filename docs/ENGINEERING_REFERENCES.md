# Engineering References

PantryPilot's engineering approach is informed by the **AI Researcher** capstone from
the UNIPDS AI-Native Engineering program.

The reference is used for patterns such as reliable retrieval-augmented generation,
source attribution, graceful degradation, testable agent flows, observability and
production documentation. PantryPilot does not reuse its financial domain, corpus or
private learning materials.

## Adaptation rule

The PantryPilot product has its own culinary corpus, source policy, safety guardrails
and user experience. Any external content considered for the corpus must be reviewed
for licensing, attribution and suitability before inclusion.
